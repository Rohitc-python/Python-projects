# Student Result Checker 📊

This is a simple Python project that checks student results and prints the result based on their marks.

---

## About
This project is useful for understanding how student results are evaluated using conditions.
It uses Python classes and if-else logic to determine whether a student is a topper, pass, or fail.

---

## Features
- Uses Python class and object
- Uses class variable
- Uses if-elif-else conditions
- Prints result based on marks

---

## Technologies Used
- Python 🐍
