# Employee Age Eligibility Checker 🧑‍💼

This is a beginner-friendly Python project that checks
whether a person is eligible based on age input.

---

## 📌 About
I created this project to practice Python basics such as
functions, conditions, loops, and exception handling.
It simulates a simple eligibility check used in companies.

---

## 🛠 Concepts Used
- Functions (`def`)
- If-elif-else conditions
- While loop
- Exception handling (`try-except`)
- User input & output

---

## 🎯 Purpose
- Check employee eligibility based on minimum age
- Prevent invalid input using error handling
- Improve user interaction with clear messages

---

## ▶️ How to Run
python main.py
